# Task Tracker API

REST API для управления проектами, спринтами и задачами с ролевой моделью доступа.  

## Основные возможности

### Аутентификация
- Регистрация, авторизация, обновление токена, выход из системы
- Получение информации о текущем сотруднике

### Сотрудники
- Просмотр профиля сотрудника
- Просмотр своих задач
- Выдача ролей только через админку

### Проекты
- Создание и управление проектами 
- Просмотр проектов, в которых разработчик состоит

### Спринты
- Создание и редактирование спринтов 
- Просмотр спринтов проекта

### Задачи
- Создание и управление задачами 
- Назначение исполнителя
- Просмотр своих задач и задач команды
- Изменение статуса задачи с бизнес-валидацией

## Требования
* **Python:** 3.10-3.12

### Статусы задач
Реализована матрица допустимых переходов статусов в зависимости от роли сотрудника.
